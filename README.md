## このプロジェクトについて

普段デザイン業務をしているメンバーが、AIツール（Claude Codeなど）とフロントエンドの基礎（HTML / CSS / JS）を、実際に手を動かしながら学ぶための個人プロジェクトです。

学んだことをメモとして溜め込むだけでなく、最終的には1つの動くWebアプリという形に残すことをゴールにしています。

「デザインはできるけど、コードはまだ自信がない」「AIツールをどう開発に活かせるのか知りたい」という気持ちからスタートしました。

## ゴール

- HTML / CSS / JS の基礎を理解し、自分の手でWebページを組み立てられるようになる
- Claude CodeなどのAIツールを使った開発の進め方を体験する
- 学びの過程を、実際に動くアプリという成果物の形に残す

## ローカルで見る方法

React版のサイト（`web-react/`）は以下の手順でローカルに立ち上げて確認できます。

```bash
cd web-react
npm install   # 初回のみ
npm run dev
```

ターミナルに表示されるURL（例: `http://localhost:5173`）にブラウザでアクセスすると確認できます。停止する場合はターミナルで `Ctrl + C` を押してください。

## 学習ロードマップ

トップページの「わからないを、ひとつずつ進む。」セクションが、Frontend エンジニアデビューまでの
学習ロードマップになっています。8カテゴリ・45項目をチェックしながら進められます。

- チェック状態はブラウザに保存されます（`localStorage`。端末をまたいだ共有はしません）
- カテゴリ行を押すと項目が開き、「特設ページへ」から解説ページに移動できます
- 特設ページのURL: `/#/roadmap/<カテゴリID>`（例: `/#/roadmap/javascript`）

### 内容を書き足すとき

| やりたいこと | 触るファイル |
|---|---|
| カテゴリ・項目の追加や文言修正 | `web-react/src/data/roadmap.js` |
| 各項目の解説本文を書く | `web-react/src/data/lessons/<カテゴリID>.js` |
| 書いた解説を特設ページに反映する | `web-react/src/data/lessons/index.js` に1行追加 |
| ロードマップまわりの見た目 | `web-react/src/styles/roadmap.css` |

解説本文は「これは何？ / なぜ必要？ / コードで見る / やってみる / つまずきポイント / 参考リンク」の
6ブロック構成です。書き方は `lessons/javascript.js` をそのまま真似すれば表示側の修正は不要です。
